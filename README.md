## 📦 Установка и запуск

### Требования
- Node.js (версия 18 или выше)
- npm (устанавливается вместе с Node.js)

### Клонирование репозитория
```bash
git clone https://github.com/Zow4ik/Website-Launch-AI.git
cd Website-Launch-AI
```

### Запуск dev сервера
#### Установка зависимостей
```bash
npm i
```
#### Запуск dev сервера
```bash
npm run dev
```

### Запуск build
#### Установка зависимостей
```bash
npm i
```
#### Сборка билда
```bash
npm run build
```
#### Запуск сервера для просмотра билда
```bash
npm run preview
```
